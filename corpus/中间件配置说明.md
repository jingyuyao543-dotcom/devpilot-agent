# 中间件配置说明

## 1. 服务基础配置

### 1.1 应用端口与线程

`server.port` 默认 8080，生产统一 8801~8810 区间。
`server.tomcat.threads.max` 设为 200，配合连接池最大 20 时注意比值，
线程数远大于连接池会导致大量线程排队等待连接，表现为接口 P99 抖动。

### 1.2 超时矩阵

跨服务调用必须同时设置三层超时，且外层大于内层：

| 层 | 配置 | 建议值 |
| --- | --- | --- |
| 客户端（RestTemplate/WebClient） | connect / read | 2s / 10s |
| 网关（Nginx） | proxy_read_timeout | 120s |
| 服务端（LLM 推理） | 整任务超时 | 90s |

服务端整任务超时必须小于网关，否则网关先断开，客户端拿不到错误信息。

## 2. HikariCP 连接池

```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 3000
      idle-timeout: 600000
      max-lifetime: 1800000
      leak-detection-threshold: 60000
```

`max-lifetime` 必须小于数据库侧 `wait_timeout`（MySQL 默认 28800s，云厂商常配 600s），
否则拿到已被服务端断开的连接，报 `Communications link failure`。

`connection-timeout` 建议 3s 而非默认 30s：快速失败比长时间排队更容易定位问题。

## 3. Redis

### 3.1 关键配置

- `maxmemory-policy allkeys-lru`：缓存场景用 LRU，但会话和令牌类数据不要和缓存混用同一实例。
- 禁止使用 `KEYS *`，用 `SCAN` 分批遍历。
- 大 key 阈值：String > 10KB、集合元素 > 5000 即视为大 key，会阻塞主线程。

### 3.2 会话记忆存储

Agent 多轮会话存储结构推荐：

- `chat:context:{sessionId}` —— List 类型，`LPUSH` 新消息，`LTRIM 0 9` 保留最近 5 轮（10 条），
  每次写入后 `EXPIRE 1800` 续期。
- `chat:summary:{sessionId}` —— String，滚动摘要，第 6 轮起把最老一轮并入。
- `chat:constraint:{sessionId}` —— Hash，存用户显式约束（如"只看 payment 模块"），
  **独立于对话历史**，避免滑动窗口把早期约束挤掉。

## 4. RabbitMQ

### 4.1 队列声明

```java
@Bean
public Queue docParseQueue() {
    return QueueBuilder.durable("agent.doc.parse")
        .withArgument("x-dead-letter-exchange", "agent.dlx")
        .withArgument("x-dead-letter-routing-key", "doc.parse.dlq")
        .build();
}
```

### 4.2 需要确认的三件事

1. `publisher confirms` + 手动 ACK，否则消息丢失无感知。
2. 消费者 prefetch 设为 1~5，避免一个消费者堆积大量未处理消息导致重试时放大。
3. 消息体不要塞大文件，只传 `doc_id` + 存储路径，避免消息队列被大 payload 拖慢。

## 5. 常见错误码对照

| 错误信息 | 含义 | 处理 |
| --- | --- | --- |
| `Connection is not available` | 连接池耗尽 | 查长事务与泄漏 |
| `Communications link failure` | 连接被服务端断开 | `max-lifetime` 调小 |
| `RedisCommandTimeoutException` | Redis 响应慢 | 查大 key / 慢查询 |
| `PRECONDITION_FAILED - unknown delivery tag` | 重复 ACK | 检查异常分支 |
| `413 Request Entity Too Large` | 上传超限 | 调 `client_max_body_size` |
| `504 Gateway Time-out` | 网关超时 | 检查服务端整任务超时 |
| `CORS preflight did not succeed` | 预检被拦 | 鉴权需放行 OPTIONS |
